# Wallet Setup

Halo works with Stacks-compatible wallets. This guide covers setup for the two supported wallets.

---

## Supported Wallets

| Wallet | Platform | Download |
|---|---|---|
| **Leather** | Chrome, Firefox, Desktop | [leather.io](https://leather.io/) |
| **Xverse** | Chrome, iOS, Android | [xverse.app](https://www.xverse.app/) |

---

## Setting Up Leather

1. Install the Leather browser extension from [leather.io](https://leather.io/)
2. Click **Create new wallet**
3. Write down your **24-word recovery phrase** — store it securely offline
4. Set a password for the extension
5. Your wallet is ready

### Switching to Testnet

For testing on Halo's testnet:

1. Open Leather → Settings (gear icon)
2. Select **Network** → **Testnet**
3. Your address will change to a testnet address (starts with `ST`)

---

## Setting Up Xverse

1. Install Xverse from [xverse.app](https://www.xverse.app/)
2. Click **Create Wallet**
3. Write down your **12-word recovery phrase**
4. Set a password
5. Your wallet is ready

### Switching to Testnet

1. Open Xverse → Settings
2. Select **Network** → **Testnet**

---

## Getting Testnet STX

You need STX for transaction fees. Get free testnet STX:

1. Go to the [Hiro Faucet](https://explorer.hiro.so/sandbox/faucet?chain=testnet)
2. Paste your testnet wallet address
3. Click **Request STX**
4. You'll receive 500 STX for testing

---

## Connecting to Halo

1. Visit [gethalo.fun](https://gethalo.fun) and sign in
2. Click **Connect Wallet**
3. A popup will appear from your wallet extension
4. Click **Connect** / **Approve**
5. Your wallet address will appear in the Halo dashboard

---

## Security Tips

- **Never share your recovery phrase** — Halo will never ask for it
- **Verify transaction details** before signing — check the contract address and function name
- **Use a dedicated wallet** for testing — don't connect a wallet with mainnet funds to testnet apps
- **Check the URL** — always verify you're on `gethalo.fun` before connecting
